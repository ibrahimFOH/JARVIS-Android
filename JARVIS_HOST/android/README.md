# JARVIS Android Bridge

Android istemcisi, Windows üzerindeki JARVIS `CommandProcessor` ile LAN üzerinden konuşur. Böylece mevcut masaüstü komutları, web erişimi ve Ollama akışı tek bir beyin üzerinden korunur.

Varsayılan bridge: `8765`
Varsayılan token: `JARVIS-ANDROID-2026-STAGEPULSE`

Android istemcisinde PC'nin LAN IP'sini girin. Bridge başlarken IP adreslerini konsola yazar.
