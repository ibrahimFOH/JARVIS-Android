# JARVIS Android

Bağımsız Android JARVIS uygulaması.

## Mimari
- Android uygulaması Windows JARVIS'ten tamamen bağımsızdır.
- Windows IP adresi, LAN bridge, Ollama host veya bridge token kullanmaz.
- Android SpeechRecognizer ile Türkçe sesli komut alır.
- Android TextToSpeech ile Türkçe yanıt verir.
- Stagepulse siyah / altın / beyaz HUD korunur.
- Temel Android komutları cihaz üzerinde yerel çalışır.
- Windows masaüstü JARVIS ayrı bir uygulama ve ayrı çalışma ortamıdır.

## Build
Android Studio veya GitHub Actions üzerinden build edilebilir.
