# Asistan EXE Recovery

This folder stores the verified recovery findings for Asistan 0.1.5.

- `ASISTAN_EXE_KURTARMA_RAPORU.md`: detailed Turkish report and limitations.
- `ASISTAN_EXE_KURTARMA_DURUMU.txt`: asset names, native command traces, hashes, and status.

Important: raw payload extraction is not the same as recovering valid HTML/JavaScript/CSS. No complete original source project has been recovered yet. Browser history and general WebView2 profile files are intentionally excluded from this public repository because they are personal browsing data rather than application source.
